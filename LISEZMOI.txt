votre, celui du brief 10, si vous l'avez.


IMPORTANT — si la base assurrisk n'existe plus sur votre poste
---------------------------------------------------------------
Le script 01 recree toutes les TABLES, mais pas la BASE elle-meme.
Si la connexion echoue avec "database assurrisk does not exist",
creez-la d'abord. Dans DBeaver : clic droit sur la connexion
PostgreSQL > Create > Database > nom : assurrisk.

Tout le reste du dossier est autonome : vous n'avez besoin d'aucun
fichier d'une semaine precedente.
